# 图形界面

`omy-gui` 是基于 Tauri v2 + Vue 3 的桌面与移动端界面。

## 像文件管理器一样用

界面的基本形态是文件浏览器，而不是「加密工具」：左侧是位置侧栏，右侧是条目列表，双击进入或打开（移动端是单击）。

**不需要先输密码就能进门。** 打开界面看到的是普通的文件浏览视图，`.omy` 文件显示为锁定状态。想看某个文件的内容时才输密码，输过之后同库的其他文件自动解锁。

已解锁的条目显示的是**解密后的真实文件名与缩略图**，右下角带播放路径角标（⚡ / 🔄 / 🐌），一眼能看出这个视频能不能直接流畅播放。

## 内嵌预览与播放

点开一个已解锁的媒体文件会在界面内预览：

- **视频**：可任意拖动进度条，拖动时显示对应画面预览，支持音量、倍速和前后 10 秒；移动端可横滑快进 / 快退并预览目标画面、长按 2 倍速播放。时间轴预览在内存中按需生成，不会先解密落盘
- **图片 / 音频 / 文本**：内嵌显示

所有内容通过自定义协议 `omystream://` 传输，明文不写入磁盘。这条路径的安全前提经过实测确认（响应头必须带 `Cache-Control: no-store` 等，否则 WebView 可能落盘缓存）。

## 主要功能

| 功能 | 说明 |
|---|---|
| 加密 | 选文件或文件夹，可设分块大小、KDF 档位、缩略图、原文件处置 |
| 解密 / 还原 | 单个或批量还原到指定位置 |
| 浏览 | 普通文件与 `.omy` 混合列表，锁定状态一目了然 |
| 预览播放 | 视频 seek、音量、倍速、前后 10 秒与移动端长按加速；图片音频文本内嵌 |
| 密码管理 | 加密码槽、改密码、重新加密 |
| 右键菜单 | 打开、在文件管理器中显示、密码管理、移到回收站等 |
| 设备与共享 | 发现设备、配对、浏览远端文件并直接播放 |
| 远程位置 | 连接 WebDAV 云盘 / NAS，浏览并点播 `.omy`；Android 可只读或可编辑交给外部应用打开，详见[远程位置](remote-locations) |
| 设置 | 通用、远程位置、安全与密码、加密默认值、播放与预览、设备与共享、关于（见下） |
| 主题 | 明暗主题（入口在设置的「通用」） |
| 多语言 | 简体中文 / English，按系统 locale 自动选择（入口在设置的「通用」） |

## 安全约束

界面的 CSP 是严格的：`default-src 'none'`、`script-src 'self'`，不允许 `eval` 与内联脚本。

由此带来两点：Vue 模板必须**预编译**（运行时编译器内部用 `new Function`，会被 CSP 挡掉）；脚本与样式不能作为 data URI 执行。`img-src` 单独允许 data URI，供时间轴画面预览等内存图片使用。

另外**不启用 Tauri 的 `protocol-asset`**——那个协议会直接暴露文件系统路径，与「明文不落盘」相悖。所有内容都走受控的 `omystream://`。

原生目录选择器只在 Rust 侧调用并封装成受控命令，前端拿不到任意路径选择能力（capabilities 里没有开放 dialog 权限）。

## 移动端

Android 版共用同一套组件，只换外壳——不是另写一个界面。列表、搜索、进度、统计的逻辑完全一致。

断点是 768px：以下为单栏 + 底部导航，以上为侧栏布局。转屏会实时切换。移动端底部导航为「文件 / 远程 / 设备 / 设置」四个标签，语言切换与明暗主题收在「设置 → 通用」里。文件页与远程位置页共用的顶部栏会避开系统状态栏；即使 Android WebView 没有提供安全区变量，也会保底预留 24px。

Android 打开视频预览时会自动切换到横屏，关闭预览后恢复系统方向；播放器始终使用触摸手势模型，不会因为横屏宽度超过断点而退回桌面交互。系统返回键会优先关闭当前菜单或弹窗、退出设置二级页、关闭预览或返回上一级目录，只有回到应用起点后才退出应用。移动端文件菜单以居中模态框显示，Telegram 登录不提供仅适用于桌面的 tdata 复用入口。

::: tip 触屏的交互差异
桌面靠双击打开条目，触屏上没有双击这个手势（`dblclick` 在移动 WebView 里要么不触发，要么被系统的双击缩放吃掉）。移动端单击始终打开文件或文件夹，只有长按才进入或扩展文件选择；已有选中项也不会改变单击的含义。所以打开、多选、拖拽这些交互在移动端是分别处理的，不只是 CSS 适配。
:::

移动端上有两个平台限制：没有 FFmpeg，所以视频缩略图与 P2/P3 播放不可用；没有回收站，所以不提供「移到回收站」。

### 存储访问权限

首次启动时侧栏会显示「允许访问手机文件」。授权后侧栏才会列出手机存储、存储卡、相机、手机文档、影片、音乐等位置。

用的是 Android 的全盘文件访问（`MANAGE_EXTERNAL_STORAGE`）。API 30 及以上会跳到系统设置页开启，API 29 及以下是标准的运行时权限弹窗。

::: tip 为什么不用系统的文件选择器（SAF）
SAF 给出的是 `content://` URI，重命名之后 URI 会变、已授权的权限随之失效——而加密写入依赖「同目录内原子替换」这个前提，正好被打掉。全盘访问保留了直接的文件路径。
:::

权限状态每次都实地查询，不在应用内缓存。这一点是刻意的：缓存一份「已授权」的副本，在用户到系统设置里关掉权限之后仍会显示有权限，然后每个文件操作都以权限错误失败，而错误信息完全指不到真正的原因。权限被撤销时侧栏会直接报错，而不是返回一个残缺的列表。

## 设置

桌面端设置是一个弹窗（顶栏齿轮），移动端是底部「设置」标签下的列表加二级页。分类一致：

| 分类 | 内容 |
|---|---|
| 通用 | 语言、明暗主题、默认视图（网格 / 列表）、启动时打开（上次目录 / 主目录） |
| 远程位置 | 识别范围、并发请求数，以及二级页「密文缓存」的上限、用量、清空、退出清空 |
| 安全与密码 | 自动锁定（闲置时长、切到后台是否计时、播放中豁免）、当前会话已加载密码数与立即锁定、恢复码提示 |
| 加密默认值 | KDF 档位、分块大小、加密前压缩、文件名加密方式、原文件处置；这些会成为加密对话框的初始值 |
| 播放与预览 | 是否在列表中显示缩略图（缩略图存在文件头里，显示它不需要读取正文） |
| 设备与共享 | 本机名称、局域网共享是否开机自启、已配对设备管理入口 |
| 关于 | 应用版本、OMYFILE 文件格式版本、分层开源许可、配置文件路径与便携模式 |

默认视图与启动位置是持久化的：在界面上切换网格 / 列表会记住，浏览过的目录会作为「上次目录」在下次启动时恢复。

自动锁定的语义：切到后台按**闲置**处理（是否锁定取决于闲置时长设置），正在播放媒体时不计为闲置；也可以在安全页随时「立即锁定」。

## 启动

桌面端：

```bash
cargo run --release -p omy-gui
```

Android：安装 [Releases](https://github.com/lejunyang/omy/releases) 里的 APK。

从源码构建的完整步骤见[从源码构建](/guide/building)。
